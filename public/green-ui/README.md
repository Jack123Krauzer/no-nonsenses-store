# No Nonsenses — Green UI

Collection-preview website created from the supplied dark and sage design references.

## Preview

Run the existing Next.js app with `npm run dev`, then open `http://localhost:3000/`. The homepage redirects to the complete green website at `/green-ui/index.html`. A deployment built from the `green-ui` branch behaves the same way.

Alternatively, serve this directory with any static HTTP server. No additional dependencies are needed for the preview.

## Included

- Responsive landing page, collection filters, product detail dialogs, size exploration, and FAQs.
- Original generated campaign artwork in `assets/campaign.webp`.
- Self-contained HTML, CSS, JavaScript, and favicon.

This is a concept collection preview. It does not take orders or payments. The existing Shopify integration, admin, product, and checkout routes remain available at their existing paths.
