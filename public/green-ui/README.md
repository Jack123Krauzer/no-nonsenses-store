# No Nonsenses — Green UI

Standalone collection-preview website created from the supplied dark and sage design references.

## Preview

Run the existing Next.js app with `npm run dev`, then open `http://localhost:3000/green-ui/index.html`.

Alternatively, serve this directory with any static HTTP server. No build step or additional dependencies are needed for this preview.

## Included

- Responsive landing page, collection filters, product detail dialogs, size exploration, and FAQs.
- Original generated campaign artwork in `assets/campaign.webp`.
- Self-contained HTML, CSS, JavaScript, and favicon.

This is a concept collection preview. It does not take orders or payments. The existing store, Shopify integration, admin, and checkout code are preserved. The preview is not wired into the Next.js homepage.
